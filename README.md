# FitLog 🏋️

FitLog is a responsive workout tracking web application built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Features

* Responsive design for mobile, tablet, and desktop
* Browse workout exercises
* View workout details
* Save favorite workouts
* Add workouts to My Plan
* LocalStorage support
* Async/Await data fetching
* Next.js App Router
* Figma-based UI

## 💻 Technologies Used

* Next.js
* TypeScript
* Tailwind CSS
* React
* LocalStorage
